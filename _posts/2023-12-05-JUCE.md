## 1) HelloWorld — custom component & mouse events

**Key functions/classes**

* `paint(juce::Graphics&)`: draw background + text.
* `mouseDown(const juce::MouseEvent&)`: update state on click.
* `mouseUp/ mouseDrag` (optional): alternate interactions.
* `repaint()`: schedule redraw.
* `getLocalBounds()` / `drawFittedText(...)`: layout + text rendering.

```c++
// MainComponent.cpp (minimal)
void MainComponent::paint (juce::Graphics& g) {
  g.fillAll (colours[idx]);
  g.setColour (juce::Colours::black);
  g.setFont (24.0f);
  g.drawFittedText (greetings[idx], getLocalBounds().reduced(20),
                    juce::Justification::centred, 1);
}

void MainComponent::mouseDown (const juce::MouseEvent& e) {
  lastClick = e.getMouseDownPosition();
  idx = (idx + 1) % greetings.size();
  repaint();
}
```

## 2) GUI Basics — buttons, sliders, combos

**Key functions/classes**

* `addAndMakeVisible(component)`: attach to UI.
* `resized()`: layout widgets.
* `juce::TextButton::onClick`: action callbacks.
* `juce::Slider::onValueChange`: reactive parameter updates.
* `juce::ComboBox::onChange` / `addItem(...)`: mode selection.
* (Alt style) `Button::Listener`, `Slider::Listener`, `ComboBox::Listener`.

```c++
// Wiring callbacks
playButton.onClick = [this]{ startOrStop(); };

// Layout

  gainSlider.setBounds(r.removeFromTop(28)); r.removeFromTop(8);
  modeCombo.setBounds(r.removeFromTop(28));
```

**Key functions/classes**

* `juce::AudioFormatManager::registerBasicFormats()`
* `juce::FileChooser` + `createReaderFor(...)`
* `juce::AudioTransportSource::setSource/start/stop`
* **Audio callbacks:** `prepareToPlay`, `getNextAudioBlock`, `releaseResources`
* **UI sync:** `juce::Timer::timerCallback()` or `ChangeListener::changeListenerCallback(...)`
* Time helpers: custom `formatTime(double)`; position slider normalized 0–1

```c++
// Set source & start/stop
formatManager.registerBasicFormats();
auto* reader = formatManager.createReaderFor (file);
readerSource.reset (new juce::AudioFormatReaderSource (reader, true));
transport.setSource (readerSource.get(), 0, nullptr, reader->sampleRate);

playPause.onClick = [this]{
  transport.isPlaying() ? transport.stop() : transport.start();
};

// Audio path with gain
void MainComponent::getNextAudioBlock (const juce::AudioSourceChannelInfo& info) {
  transport.getNextAudioBlock(info);
  if (info.buffer) info.buffer->applyGain (currentGain);
}

// UI update tick
void MainComponent::timerCallback() {
  const auto len = transport.getLengthInSeconds();
  if (len > 0.0) {
    posSlider.setValue (transport.getCurrentPosition() / len, juce::dontSendNotification);
    timeNow.setText (formatTime(transport.getCurrentPosition()), juce::dontSendNotification);
    timeEnd.setText (formatTime(len), juce::dontSendNotification);
  }
}
```

## 4) Wave Lab — wavetable oscillator (synth building block)

    <div class="col-sm mt-3 mt-md-0">

    </div>
</div>

**Key functions/classes**

* `setFrequency(float f, double sampleRate)`: compute `tableDelta = f * tableSize / sampleRate`
* `getNextSample()`: fractional index, linear interpolation, phase wrap
* Render hooks: `renderNextBlock(...)` (custom) or call in `getNextAudioBlock(...)`
* Table gen: fill `juce::AudioBuffer<float>` with a cycle (sine/saw/square), optional `juce::dsp` utilities

```c++
class WavetableOsc {
public:
  void setFrequency (float f, double sr) { tableDelta = f * (float)tableSize / (float)sr; }
  float getNextSample() {
    auto i0 = (unsigned) idx, i1 = (i0 + 1) % tableSize;
    float frac = idx - i0;
    float out = table[i0] + frac * (table[i1] - table[i0]);
    idx += tableDelta; if (idx >= (float)tableSize) idx -= (float)tableSize;
    return out;
  }
private:
  std::vector<float> table; int tableSize { 2048 };
  float idx { 0.f }, tableDelta { 0.f };
};
```

**Key functions/classes**

* `juce::AudioDeviceManager::initialise(...)`
* `juce::AudioDeviceSelectorComponent` (modal settings dialog)
* `juce::MidiInput::getAvailableDevices() / openDevice(...) / start(...)`
* `handleIncomingMidiMessage(...)` (from `juce::MidiInputCallback`)
* Helpers: `MidiMessage::isNoteOn/isNoteOff/isController`, `getNoteNumber()`, `getVelocity()`
* (Optional) `juce::MidiKeyboardState` + `juce::MidiKeyboardComponent`
* (Sampler) `juce::AudioProcessorPlayer` + SFZ/SF2 loader, `processBlock(...)`

```c++
// Open settings
void openAudioSettingsDialog() {
  juce::DialogWindow::LaunchOptions o;
  auto comp = std::make_unique<juce::AudioDeviceSelectorComponent>(
      deviceManager, 0, 2, 0, 2, true, true, true, false);
  comp->setSize(520, 260);
  o.content.setOwned(comp.release());
  o.useNativeTitleBar = true;
  o.dialogTitle = "Audio/MIDI Settings";
  o.launchAsync();
}

// MIDI callback
void handleIncomingMidiMessage (juce::MidiInput*, const juce::MidiMessage& m) {
  if (m.isNoteOn())  appendToLog("NoteOn "  + juce::String(m.getNoteNumber()));
  if (m.isNoteOff()) appendToLog("NoteOff " + juce::String(m.getNoteNumber()));
  if (m.isController())
    appendToLog("CC " + juce::String(m.getControllerNumber()) + " = " +
                juce::String(m.getControllerValue()));
}
```
